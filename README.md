# Git Lab

Ovo je projekt za Vježbu 2 iz mrežnog programiranja.

## Opis

U ovoj vježbi koristi se Git za verzioniranje koda.  
Cilj je naučiti osnovne Git naredbe kao što su inicijalizacija repozitorija, dodavanje datoteka u staging područje i izrada commita.

## Korištene naredbe

- `git --version`
- `git config`
- `git init`
- `git add`
- `git commit`
